Dogecoin explorer documentation

Blocks, transactions and addresses

Search a block height, block hash, transaction ID, transparent Dogecoin address, or supported explorer URL. A 64-character hash may belong to several chains; manual chain selection stays available.

Dogecoin targets one block every 2.5 minutes. Difficulty adjusts every 2,016 blocks. The block subsidy halves every 840,000 blocks.

1 DOGE = 100,000,000 koinu. Fee rates use koinu/B. Fiat values use the provider's Dogecoin prices and may lag the market.

Privacy and coverage

The transaction and address views show the transparent chain. MWEB hides transfer amounts and recipient history; a public explorer cannot reconstruct these private details. HogEx and peg-in/peg-out data must not be interpreted as ordinary wallet transfers.

The pending view reflects a node’s mempool; different nodes may see different transactions. Estimates are not confirmation guarantees.

Read-only API

Requests use the same local origin. Successful retained responses carry X-DOGE-Observed-At and X-DOGE-Stale headers. Provider failures return 503; absence returns 404. This local review does not broadcast transactions.
